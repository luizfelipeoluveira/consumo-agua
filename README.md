## 🎯 Objetivo

Sistema desenvolvido em **Python** para classificar o perfil de consumo de água de imóveis, considerando:

* 🏠 Tipo de imóvel: **casa, apartamento ou comercial**
* 💧 Consumo mensal em **m³**
* 🔔 Alertas educativos personalizados

O sistema busca incentivar o **consumo consciente de água** por meio da análise dos dados informados.

## 🛠️ Tecnologia utilizada

**Python** — linguagem utilizada no desenvolvimento do sistema.

## ▶️ Como executar

1. Tenha o **Python 3.14** instalado.
2. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

3. Execute o programa:

```bash
python app.py
```
